# CloudVault ☁️

CloudVault is a simple Cloud-Based File Storage and Sharing System developed as an academic Cloud Computing project.

The project demonstrates how cloud computing can be used to provide centralized file storage and access through an internet-based application.

## Project Objective

The main objective of CloudVault is to demonstrate the basic concept of cloud-based file storage.

Instead of storing files only on a local computer, cloud storage allows users to store their data on remote servers and access it through the internet.

## Features

- Cloud storage dashboard
- Storage usage indicator
- File management interface
- File categories
- Download interface
- Cloud storage features
- Secure access concept
- Anywhere-access concept
- Scalable storage concept
- Basic cloud architecture
- Responsive web design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Cloud Computing Concepts

### 1. Cloud Storage

Cloud storage allows data to be stored on remote servers instead of only on a local device.

### 2. Scalability

Cloud storage can be expanded according to the user's storage requirements.

### 3. Accessibility

Cloud-based files can be accessed from different devices through an internet connection.

### 4. Security

Cloud applications can use authentication and access-control mechanisms to protect user data.

### 5. Centralized Data Management

Files can be managed from a centralized cloud-based storage system.
